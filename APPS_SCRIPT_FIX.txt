PERBAIKAN RESPONSE GOOGLE APPS SCRIPT
=====================================

Penyebab error pada frontend:
index.html sebelumnya mengecek responseData.id, sedangkan Apps Script versi terakhir hanya mengembalikan success:true tanpa id.

Pada bagian akhir doPost(e), gunakan response sukses seperti ini:

return ContentService
  .createTextOutput(
    JSON.stringify({
      success: true,
      id: id,
      nama_kepala_keluarga: namaKepala,
      nik_kepala_keluarga: nikKepala
    })
  )
  .setMimeType(ContentService.MimeType.JSON);

Pada bagian catch gunakan:

return ContentService
  .createTextOutput(
    JSON.stringify({
      success: false,
      error: error.toString()
    })
  )
  .setMimeType(ContentService.MimeType.JSON);

PENTING:
Setelah menyimpan Apps Script, buka Deploy > Manage deployments > Edit > New version > Deploy.
Pastikan URL /exec yang dipakai index.html adalah URL deployment yang aktif.
